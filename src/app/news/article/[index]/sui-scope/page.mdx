The Sui ecosystem is evolving rapidly. As the network scales, the way decentralized applications (dApps) query data is fundamentally changing. Legacy JSON-RPC is being phased out in favor of more efficient, specialized data-serving architectures: **GraphQL, gRPC, and Archival nodes.**

For developers, this transition raises a critical question: *Which infrastructure provider should I route my traffic to for the best performance?*

Today, Ruby Nodes is thrilled to announce the launch of **[SuiScope](https://scope.rubynodes.io/)** — a continuous, neutral, and public-good benchmarking platform built specifically for Sui developers.

## Why We Built SuiScope

When building highly responsive dApps, every millisecond counts. Developers need unbiased, real-world data to evaluate how different endpoints perform under actual network conditions.

SuiScope does not simulate internal server behavior. Instead, it measures the **actual client experience** using stateless probe agents deployed across multiple geographic regions.

## Key Features for Developers

* **Real-World Metrics:** We track cold-connection latency, time-to-first-byte (TTFB), uptime, and error rates. Our methodology strictly prohibits connection pooling or caching, ensuring the data reflects true network requests.
* **State Freshness:** We benchmark providers directly against a trusted Mysten Labs reference endpoint to ensure the data you receive is perfectly in sync with the chain head.
* **Compare Providers:** A visual dashboard allowing you to compare up to 4 providers side-by-side over 24-hour or 7-day windows.
* **Free Public API:** Need to build custom alerting or implement smart provider routing directly into your dApp? All our pre-aggregated data is available via a free REST API with no authentication required.
